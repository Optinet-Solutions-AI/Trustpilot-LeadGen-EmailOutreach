OptiRate/ facebook · the honest part
08 / 10
Straight talk

Facebook works locally —
cloud is still in progress.

✓ Works today — on a local machine
A logged-in Facebook session on a real Windows + browser setup scrapes successfully. Validated end-to-end: full authenticated homepage, no login wall, no captcha.
  • Real consumer browser fingerprint passes Meta's checks
  • Session cookies stored encrypted & reusable
  • Same scraper code path as the live platforms
⟳ Not yet — on cloud servers
Run unattended from a datacenter server, Meta bounces it back to the login screen. The block is fingerprint-level, not credentials — the server simply doesn't look like a real person's computer:
  • WebRTC leaks the datacenter IP via STUN
  • WebGL renders with no GPU — a classic bot tell
  • No media devices (mic/webcam) that real users have
  • Server-OS fonts differ from a consumer desktop
The path forward → A Windows-based cloud worker with one browser profile per operator + a residential proxy. The exact combination that fails on a Linux server has already been smoke-tested as working on Windows. That build is the next milestone.
